Sobre o Sistema

Cadastro de Inventário de Softwares de TI

O sistema é um projeto demonstrativo para registrar softwares, versões, tipo de licença, responsável e data de renovação. Os dados são mantidos no armazenamento local do navegador.

O que o sistema faz

Cadastro e consulta de softwares.
Registro de versão, licença, e-mail responsável e renovação.
Situação calculada pela data: ativa, próxima do vencimento ou vencida.
Exclusão de registros da lista.

O sistema não tem servidor, banco de dados nem login. Cada navegador mantém sua própria lista; ela não é compartilhada com outras pessoas ou dispositivos.

Limitações

A página de login é apenas demonstrativa. O sistema também não envia mensagens nem sincroniza os dados entre dispositivos. Limpar os dados do navegador pode apagar os registros.
